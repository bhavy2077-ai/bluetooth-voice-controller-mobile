# 🎙️ Bluetooth Voice Controller - Mobile App

## Overview
Android application that receives and executes voice commands from laptop via Bluetooth.

## Features
✓ Bluetooth server socket communication
✓ AES-256 encryption
✓ Real-time command execution
✓ Material Design UI
✓ Android 12+ support

## Supported Commands
- "open youtube" → Opens YouTube
- "call [number]" → Makes call
- "open home screen" → Home screen
- "open messages" → SMS app
- "open camera" → Camera
- "open settings" → Settings

## Build & Install
```bash
./gradlew build
./gradlew installDebug
```
